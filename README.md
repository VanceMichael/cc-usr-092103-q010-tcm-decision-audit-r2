# 方证辅助诊疗审计

界定中医辅助诊疗模型在多机构部署时的审计信息，并提供可运行的审计骨架：机构登记、推理留痕、不可变事件、审计重放、患者视图与科研导出。

## 领域资料

仓库中的 `contracts/` 描述资料格式，`fixtures/` 给出可公开使用的示例。代码库负责读取、校验并基于这些资料运行审计逻辑，业务服务可沿用相同标识和版本约定。

- `fixtures/terminology.json` — 方证术语：证型、方剂、病种与名医经验来源（按版本管理）
- `fixtures/institutions.json` — 机构层级：龙华医院总院/各院区、区域医疗中心、医联体，及各机构登记的模型版本、适用范围（病种）与停用条件
- `fixtures/roles.json` — 角色与权限：医师、主任医师、审计员、科研人员、机构管理员、患者
- `fixtures/model_versions.json` — 模型版本规则表，每条规则标注名医经验来源版本
- `fixtures/inference_request.json` — 推理调用样例（仅含脱敏最小特征）

## 需求与模块映射

| 需求 | 实现 |
| --- | --- |
| 审计重放：按当时机构权限、患者授权、获准病种、名医经验来源与实际输入重建，区分模型输出与医生最终处置 | `src/replay.py`（`replay` / `explain_difference`） |
| 机构登记版本、适用范围及停用条件（日期 / 不良事件阈值），运行期变更留痕 | `src/registry.py` + `fixtures/institutions.json` |
| 推理请求只保留最少必要的脱敏特征 | `src/minimization.py`（白名单 + 直接标识拒绝） |
| 驳回、修订、不良结果上报、授权撤回不可反向修改 | `src/events.py`（只追加 + 哈希链）+ `src/disposition.py` + `src/consent.py` |
| 灰度切换确定性 | `src/gray.py`（按机构与请求标识稳定分桶，规则整体替换） |
| 重复请求确定结果 | `src/inference.py`（request_id + 内容指纹幂等） |
| 离线补传确定结果 | `src/events.py`（按发生时间折叠快照）+ `src/inference.py`（去重与冲突拒绝） |
| 跨院会诊确定结果 | `src/consultation.py`（共享仅限脱敏特征，结论唯一） |
| 患者端只显示医生确认内容 | `src/patient_view.py` |
| 科研导出不得越过用途授权或还原个人 | `src/research_export.py`（用途核验 + 不可逆伪名 + 泛化） |

## 设计要点

- **事件溯源**：所有事实（推理、处置、授权、登记、灰度、会诊）都是 `EventLog` 中只追加的事件；任意时刻的状态按 `occurred_at` 折叠重建，因此"当时"的快照与写入顺序无关，离线补传自动进入其发生时刻的历史。
- **确定性**：版本解析、权限判定、重放结果只取决于事件日志与术语资料；所有接口显式传入时间，不依赖系统时钟。
- **不可变**：事件对象冻结、日志无修改接口、哈希链可校验；最终处置只能写入一次，相同内容幂等，不同内容拒绝。
- **职责分离**：模型输出冻结在决策记录中，医生的采用 / 驳回 / 修订是独立事件，重放报告与患者视图都分别呈现。

## 本地校验

运行项目自带测试即可确认样例资料可读取、领域标识与版本字段完整，且上述审计行为全部成立：

```bash
python -m unittest discover -s tests   # 或 python -m pytest -q
```

所有示例均为虚构数据，不含真实个人信息、账号或访问凭据。
